# Fake News Detection Using Machine Learning

## Overview
This project detects whether a news article is Fake or Real using Natural Language Processing (NLP) and Machine Learning techniques.

The model is trained using TF-IDF Vectorization and Logistic Regression on a labeled news dataset.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- NLP
- TF-IDF Vectorization
- Logistic Regression

---

## Features
- Data preprocessing and cleaning
- Text vectorization using TF-IDF
- Fake and real news classification
- Model training using Logistic Regression
- Accuracy evaluation
- Confusion matrix visualization
- Custom news prediction

---

## Dataset
The dataset used for this project was taken from Kaggle.

Dataset Link:
- https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

---

## Model Accuracy
Achieved approximately 98% accuracy using Logistic Regression and TF-IDF Vectorization.
